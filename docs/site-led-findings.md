# Site-led First findings — September 28, 2026

## User correction and challenge contribution

The user rejected the SVG spatial workbench and the follow-up presentation correction. Neither was user acceptance. The September 28 direction replaces the separate simulation action, generic quantity dashboard and evidence-heavy inspector with a site that develops during research, a dashboard of the person's concerns, spatial explanations, and a concise sourced first read. The dashed unplaced comparison is removed.

The original **2026 Challenge Summary, PDF pages 18–20**, was reread. This work serves the non-expert leader's preliminary affordable-housing conversation: connect public property/rule evidence to a comprehensible site study and preserve the basis for discussion materials. The 3D enhancement is explicitly user-requested. It does not complete the challenge's affordable-delivery or editable slides/talking-points requirements.

The supplied `Load message.png`, `Bad Finding.png` and `simulation representation.png` were inspected, along with the website style guide and callout reference. Outfit, neutral paper, matte architectural context, restrained green and the blue four-corner selection remain the visual basis.

## Installed behavior

- **See first findings** starts research and the scene. When the trusted assessment context is ready, Gloo starts the housing study automatically. There is no initial simulation button. Add a concern remains an intentional refinement action.
- A full-width green status banner reports actual research and study phases. It has no invented percentage. An interrupted research run keeps the available results and no longer leaves a perpetual Checking label.
- The scene is Three.js geometry, not a projected SVG illustration. Source building footprints/parts, explicit mapped heights, road lines, property geometry and the user's exact selection form the scene. Unknown heights remain flat diagram footprints. Parent footprints remain visible when only some building parts have heights.
- Real parcel candidates remain distinct before the user chooses a property. The four corners never become a legal parcel. Candidate selection remains the person's decision.
- The default architectural view is bounded to nearby context; Focus land, Neighbourhood, rotation and Plan are available. Canvas and camera survive progressive findings updates. The first camera fit waits for the mounted canvas.
- The left panel preserves the person's original concerns. Gloo interprets them, chooses actual research/calculation tools, observes errors and selects a reviewed test. Additional questions cannot silently replace the original housing purpose. Prior refinements remain in subsequent studies.
- A school question uses a real mapped-place lookup and a server-calculated straight-line distance from the selected-land centre. The result includes the named feature, source, search radius and coverage qualification. It is not a walking distance or school assignment. The selected school can be highlighted with a dashed straight-line connection.
- An answer opens a closeable detail panel. On small screens it scrolls into view; Escape closes it and returns focus. The scene precedes the dashboard and inspector on mobile.
- The right panel retains the sourced assessment headline and a short consequential condition, with full findings and sources in a readable dialog. It does not stack every record in a narrow Evidence tab.
- Mapped existing footprints are excluded from proposed homes and parking. A no-fit result leaves the land without proposed housing; there is no ghost comparison volume. Callouts distinguish the measured failure from proof that no design can work.
- Proposed blocks require a supported housing-use finding as well as the existing suppression/eligibility/version checks. Unknown use is not treated as prohibited. Absence of zoning alone no longer passes the supported-use validator. This is a necessary display gate, not certified legal capacity.
- Clicked proposed homes, parking and source buildings have different explanations. Measured numbers and the exported discussion brief use the same display gate. The brief now includes priority answers and map attribution. Actual PDF pagination and full slide/talking-point export remain unverified/unimplemented.

## Data and implementation

Pinned dependencies: `three@0.186.1`, `osmtogeojson@3.0.0-beta.5`, with the transitive XML parser overridden to `@xmldom/xmldom@0.8.15`. Browser modules are locally vendored with the Three.js license; the server does not expose node_modules. No Finch subscription, API integration or paid plugin was activated.

`scripts/site-context.mjs` uses the existing protected public-web client and a fixed Overpass endpoint. Server-built queries are bounded in geography, response size and time. Invalid/incomplete geometry is rejected. The context has separate versions and attribution; it does not become legal zoning evidence or establish vacancy, ownership or public access. Public Overpass is a prototype dependency with availability and coverage limits, not a promise of nationwide completeness.

The school lookup searches mapped `amenity=school` features. The retained Midtown case returned **151 m to Laboratory Institute of Merchandising**. That is the nearest tagged result found, not a verified nearest elementary/public school. School type, operation, walking route and attendance eligibility need appropriate sources or a material clarification.

Research and scenario workflows remain real Gloo tool loops. The daily local model-call cap stays removed. Existing per-investigation time/tool/round limits and privacy/citation checks remain. Early school lookup is encouraged and supported by exact-excerpt receipts; one successful run answered it during the later scenario stage, and another returned it before property research was interrupted. Do not claim consistently early answers from this sample.

## Material limits

This is sourced architectural massing context and a bounded detached-block study, not Finch's apartment/floorplate engine or a rendered architectural design. Roof forms, terrain and unrecorded heights are not invented. One assumed dwelling per block, spacing, edge clearance, storeys and parking geometry remain assumptions. No complete regulatory buildable envelope, circulation/egress solution, affordable-rent delivery, funding plan, expert feasibility or legal unit count is established. Sources and expert decisions remain essential.

The application still needs more predictable research completion, richer housing typologies, and the core presentation deliverables. Passing tests, a polished city scene, or one successful live run is not acceptance of the experience and does not prove the challenge is complete.
