# First findings presentation correction · September 26, 2026

The initial workspace was rejected by the user: the selected strip was tiny on an empty plane, narrow sidebars contained too much small text, and zero homes appeared beside an assumed height. This correction changes the default information hierarchy and framing, not the property evidence or Gloo tool loop.

## Implemented

- Selected-land framing is the default; a whole-property inset toggles context. Valid calculated blocks remain matte white massing.
- Left: large land area and only relevant quantities. Failed tests show footprint dimensions and “No layout placed”; no building height or home capacity is established.
- Failed tests have a dashed, explicitly unplaced volume using the tested dimensions, positioned illustratively. This is an explanatory size comparison, not a new layout or proposed location. The editable brief preserves that distinction.
- Right: Overview/Evidence tabs, short status and layout outcome, an explicit adjustment action. Full existing assessment, obstacles, citations and records move into a readable dialog. The landmark flag remains visible at first glance for the New York case.
- Numbered priority pins are inside the scene, opening an animated detail card with Gloo's interpretation and the user's exact excerpt. Free-text refinement still invokes the existing real Gloo agent; no local interpretation fallback was added.
- Readable panel body text (17–18px), labels 15px or larger, responsive layout, keyboard tab selection, Escape and focus return, reduced motion support. SVG annotation sizes adjust to retain readable on-screen text.

## Checks and boundaries

The original Challenge Summary pages 18–20 and the supplied simulation representation were reread/inspected for this correction. The change supports a non-expert leader's quick preliminary read; it does not complete the address-to-presentation challenge journey.

`npm run check` passed and all existing 100 tests passed. Two new presentation tests check that unplaced size comparisons cannot establish homes, parking or height, do not mutate source geometry, and do not replace placed quantities.

Browser checks used the installed app and two clearly labelled local fixtures: retained New York evidence (`final11-NewYorkOriginal-cold.json`, parcel 1012860001, about 122 m² selected) with a deterministic no-fit test; and synthetic larger geometry with 12 measured blocks and eight parking bays. Synthetic geometry is only a visual/interaction test. Records, original source disclosures, tab keyboard navigation, dialog Escape/focus return, priority callouts and responsive overflow were checked. Mobile exposed overlapping pins, which were separated. The main live app completed a new Gloo scenario on its retained 91 m² Houston selection; it returned no fit and displayed the 6 × 10 m test comparison. Reload retained that assessment and scenario.

This is still a bounded detached-block study. It does not model surrounding buildings, terrain, apartment or rowhouse planning, site-specific legal capacity, safe access/egress or affordable delivery. The visuals must not be described as equivalent to Finch's full modelling capabilities. Actual saved-PDF pagination and complete editable slides/talking points were not verified by this correction.
